Review Lens privacy policy

Effective 07|10|2026 (updated for v1.3.8: optional email and anonymous usage count)

Review Lens is a browser extension that summarises the reviews and comments on a web page into themes. It has no accounts and no ads. It counts how many installs are in use each day without any personal data, and it asks for your email only if you choose to share it.

What data is used, and when

  • Page text. Only when you click the Review Lens icon (or press its shortcut), the extension reads the visible text of the current tab, or only the text you selected. On YouTube and Reddit it reads only the comments and the video or post title. It never reads pages on its own or in the background.
  • A random install ID. On first use the extension creates a random ID (not linked to you, your account or your device) so the free tier can count each install's daily analyses.
  • Your Gemini API key (optional). If you add your own key, it is stored only in your browser (chrome.storage.local) and is sent only to Google's Gemini API.
  • Daily active signal. At most once a day, when you run an analysis, the extension sends only its random install ID to the Review Lens server, so the developer can count active installs. No page text, URL or personal data is included. These records are deleted automatically after 40 days.
  • Your email (optional). Only if you type it into Settings. It is stored on the Review Lens server with your install ID and is used only to tell you about new features. Clicking "Remove email" in Settings deletes it from the server.
  • Analysis results. Your last 20 analyses are stored only in your browser so you can compare them. Removing the extension deletes them.

Who receives it

Free tier (default): the page text and your random install ID are sent to the Review Lens server (a Cloudflare Worker run by the developer), which forwards the text to Google's Gemini API and returns the result. The server does not store or log the page text. It stores only a daily usage counter per install ID, which is deleted automatically after 2 days.

With your own key: the page text is sent directly from your browser to Google's Gemini API (generativelanguage.googleapis.com). Only the daily active signal (and your email, if you shared it) goes to the Review Lens server.

Cloudflare hosts the server under the Cloudflare Privacy Policy. Google processes the request under the Gemini API Terms and Google Privacy Policy. Note that on Gemini's free tier, Google may use requests to improve its products, so avoid analysing pages with private information.

What we don't do

  • We don't sell or share your data, including your email. We don't store page text.
  • We don't track browsing history or use cookies.
  • We don't use the data for advertising, credit decisions or anything other than the analysis you requested.

Permissions

  • activeTab and scripting: read the current tab's text only after you click the icon.
  • storage: keep your install ID, optional key, settings and recent analyses in your browser.
  • generativelanguage.googleapis.com: send the analysis request to Gemini.
